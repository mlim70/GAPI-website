# Executive Committee Member Photos

This directory contains placeholder files for executive committee member photos. To add actual photos:

## File Naming Convention
Replace the `.md` files with actual image files using these names:

- `lalitha-medepalli.jpg` - Lalitha Medepalli, MD, FACC (President 2024-25)
- `satish-cheti.jpg` - Satish Cheti, MD (Vice President 2024-25)
- `appavuchetty-soundappan.jpg` - Appavuchetty Soundappan, MD (Secretary 2024-25)
- `jai-surana.jpg` - Jai Surana, MD (Treasurer 2024-25)
- `vishal-sharma.jpg` - Vishal Sharma, MD (President Elect 2024-25)
- `sreeni-gangasani.jpg` - Sreeni Gangasani, MD (BOT Chair 2024-25)
- `raj-alappan.jpg` - Raj Alappan, MD (Past President 2023-24)

## Image Requirements
- **Format**: JPG or PNG
- **Size**: Minimum 300x300 pixels (square aspect ratio recommended)
- **Style**: Professional headshots
- **Background**: Clean, professional setting
- **Quality**: High resolution for web display

## Usage
Once photos are added, they can be imported and used in the ExecutiveCommittee.tsx component to replace the placeholder SVG icons.
